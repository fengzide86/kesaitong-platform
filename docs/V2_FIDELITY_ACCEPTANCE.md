# 亚马逊 V2 高还原样板：本地验收

## 本轮范围

这是用户同意先验收的第一块样板，不是全站复刻完成，也不是新版真实执行工具。它取代 `/demo` 中原先简化的卡片式演示；官网首页、比赛/课程页面、工具介绍、价格、搜索及品牌界面、Windows 工具箱均保持原有代码。

本地入口：<http://127.0.0.1:4300/demo>。

- 课程地图：原图的深色导航、左侧通知/任务/资料查询、右侧中国与北美地图及八个入口；Amazon 弹窗保留三入口层级。
- 卖家后台：十组主菜单、头部搜索和帮助/设置位置；用户已排除的菜单登记但不深入。
- 库存：父项及可展开子变体、SKU/标题/商品编码检索、在售/不可售与配送筛选、价格筛选、批量停售/出售、自配送、行内数量/价格和列表回读。
- 商品发布：类目选择、重要信息、变体、报价、合规信息、图片、描述、关键字、更多详情八页；多行子 SKU、删除/恢复、主图及 SKU 图、本地草稿、保存并完成、校验错误定位及刷新回读。
- 国内仓库样例：先从管理订单打开确认页，再分拣、打包、选择承运人出库、查记录取运单、回同一订单确认。重复确认不再扣库存。
- 一键操作：商品发布、订单发货两个任务，驱动同一套按钮和表单，不根据等待时长假造完成；支持暂停/继续/停止。

本轮没有接真实平台、账号、业务 API、授权、Runner 或遥测，也没有部署、推送或重打 Windows 安装包。旧安装包未包含本轮模拟页面变更。

## 用户验收顺序

1. 打开课程地图，点 Amazon，再点“亚马逊卖家后台”。看导航、搜索和布局是否接近熟悉的 V2。
2. 从库存进入管理库存，展开一个父商品，试 SKU 搜索、状态和亚马逊配送筛选。
3. 点添加新商品，选择收纳袋类目，在八页之间切换；添加两个子 SKU、填写报价/重量/要点等，先存草稿，再保存并完成。
4. 在库存搜索新的父 SKU，展开核对两个子 SKU；刷新后再次编辑，检查之前填写的字段。
5. 点顶部“课赛通工具”，运行商品发布；试暂停、继续及停止，再到库存查看实际保存结果。
6. 运行订单发货，检查订单 → 国内仓库 → 运单 → 原订单的完整链路。

手机保留表单可用性。地图和多列库存/变体表在自己的区域内横向滚动，不强行缩成不同的卡片流程；当前验收来自浏览器窄视口，不是真手机设备实测。

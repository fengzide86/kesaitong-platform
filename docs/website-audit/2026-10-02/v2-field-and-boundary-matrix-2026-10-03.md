## 1. 商品标识关系

证据列约定：`现场回读` 表示在有效会话页面或详情中直接看到；`静态字段` 表示前端/旧资料线索；`现场+静态` 表示两者都出现但仍需按当前类目复核。接受条件和脚本输入边界不是评分结论。

| 对象 | 当前字段 | 证据等级 | 接入规则 |
| --- | --- | --- | --- |
| 产品上下文 | `DS2001` | 静态/现场页面线索 | 不固定写死，随页面上下文获取 |
| 外部产品编号 | `DS20169` | 静态前端字段 | 与动态类目/编码类型一起校验 |
| 外部编号类型 | `DS20170` | 静态前端字段 | 不能把 UPC/EAN/GCID 互换 |
| 父级/产品编号 | `DS2083` 等 | 静态/现场字段 | 保存前必须非空，动态 SKU 以页面回读为准 |
| 子 SKU | 变体模型/库存行 | 现场回读 | 不从旧 JSON 空 `item_sku` 猜测 |
| ASIN | 库存/广告组详情 | 现场回读 | 广告选择使用当前 FBA 行实际 ASIN |
| FNSKU | FBA 库存行 | 现场回读 | 只作 FBA 回读，不当作广告输入 |

## 2. 商品字段族

| 字段族 | 代表字段/模型 | 当前结论 |
| --- | --- | --- |
| 标题/品牌 | `DS2024`、`DS20171` | 页面和保存模型均有；具体类目必填需现场确认 |
| 价格/库存 | `DS2071`、`DS20179`、`DS20180` | 有范围校验；动态类目可能改变显示 |
| 配送/履约 | `DS2061`、`DS20178`、`DS20184`、`DS20192` | 与模板、处理时间、补货日期联动 |
| 内容 | `DS2050`、`DS2088`、`DS2094` | 旧资料可作为候选，不直接当评分答案 |
| 重量/尺寸 | `DS2053`、`DS2058`–`DS2060` | 单位必须与数值一起保存；非数字归零是风险 |
| 动态属性 | `AID`、`title`、`helptext`、`types`、`Exp` | 由服务端按类目返回，不能从字段名猜必填/得分 |
| 变体 | `DS2301`、`DS2302` 等 | 至少一条、SKU 不重复、数量/价格范围需回读 |

## 3. 状态契约

| 链路 | 页面状态 | 真实完成条件 |
| --- | --- | --- |
| 商品保存 | 编辑页 → 列表 | 业务 `Code/Msg` 成功 + 列表/详情出现对象 |
| 模板保存 | 编辑页 → 模板列表 | 保存响应成功 + 列表/基础/关系回读 |
| FBA 转换 | 转换表单 → 亚马逊库存 | 危险品信息提交 + FBA SKU/ASIN/FNSKU 回读 |
| 商品推广 | 创建页 → 已安排/草稿 | 保存响应 + 活动列表 + 广告组商品详情 |
| Prime | 商品验证 → 等待中 | FBA SKU 验证 + 保存弹窗 + 列表状态 |
| 秒杀 | 搜索 → 推荐 | 必须有推荐商品；无推荐不能伪造提交成功 |
| 发货 | 仓库 → 订单 | 分拣、打包、运单、最终确认和发货记录全部回读 |

## 4. 旧资料与 V2 兼容标记

- `已确认`：当前 V2 页面/请求/回读直接观察到。
- `静态候选`：前端源码或旧脚本出现，但当前账号未验证。
- `不兼容`：旧主机、旧选择器、旧参数或旧状态契约，不能直接复用。
- `待验证`：需要权限恢复后现场抓取。

本阶段不把“页面上有控件”直接标为得分点，也不把旧脚本固定值直接写成 V2 默认值。

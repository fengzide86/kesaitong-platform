# V2 补货、库存与商品字段只读证据（2026-10-04）

本文件承接本轮现场续采，只记录脱敏后的接口路径、字段名、类型、触发条件和页面状态；不保存完整 `paras`、Cookie、Token、密码或原始商品标识。

## 1. 订单列表读取

从卖家后台顶部“订单”进入订单列表，当前会话已恢复。两个读取接口均返回 HTTP 200、业务 `result.Code=0`，但当前账号/课程上下文没有订单行：

| 页面动作 | 脱敏接口路径 | HTTP | 业务返回 | 当前结果 |
|---|---|---:|---|---|
| 打开订单列表 | `/ECrossAmazon/GetOrderStatusNum` | 200 | `Code=0`，`jsonStr=[]` | 状态汇总为空 |
| 打开订单列表 | `/ECrossAmazon/GetOrderList` | 200 | `Code=0`，`jsonStr=[]` | 订单列表为空 |

空列表只说明当前上下文没有可读订单对象，不能推断接口未实现，也不能据此生成发货对象。

## 2. 库存商品列表读取

从顶部“库存”进入“管理库存”，现场请求如下：

| 页面动作 | 脱敏接口路径 | HTTP | 业务返回 | 结果 |
|---|---|---:|---|---|
| 打开所有库存 | `/ECrossAmazon/GetSellerProductList` | 200 | `Code=0` | 返回 9 条变体行 |
| 库存重复检查 | `/ECrossAmazon/GetProductListRepeat` | 200 | `Code=0`，`jsonStr=[]` | 未发现重复结果 |

`GetSellerProductList` 的每行返回包含 64 个字段名（本次只记录字段名和类型，不记录值）。字段可分为：

- 商品/变体上下文：`DS2001`、`DS2301`、`DS2302`、`DS2303`、`DS20169`、`DS2083`、`DS20170`。
- 标识与目录：`DS2013`、`DS2029`、`DS2047`、`DS2307`、`DS2309`、`DS2312`、`DS2326`、`DS2327`。
- 标题、图片与时间：`DS2024`、`DS2048`、`DS2010`、`DS20149`、`DS2313`、`DS2314`、`DS2320`。
- 价格与库存：`DS2305`、`DS2306`、`DS2045`、`DS2071`、`DS20112`、`DS2082`、`DS0701`、`DS0705`、`DS0708`、`orderNum`、`skuOrderNum`。
- 商品质量/评分相关：`DS2021`、`DS2089`、`DS2090`、`DS2091`、`DS2094`、`DS2095`、`DS2096`、`DS2097`、`DS2088`。
- 状态/开关/扩展：`DS2014`、`DS2018`、`DS2019`、`DS20109`、`DS20117`、`DS20180`、`DS20300`、`DS20301`、`DS2316`、`DS2317`、`DS2318`、`DS2319`、`DS2321`、`DS2343`、`A1058`。

类型边界：数值、字符串和 null 均存在；`DS2307`、`DS2069`、`DS2070`、`DS2317` 等字段在本批数据中出现 null；`DS20180` 在本批数据中为空字符串。脚本不能把空字符串、null、0 混成同一种“未填”。

## 3. 配送类型筛选与页面动作

库存页可见筛选：商品状态（所有/在售/不可售）、配送类型（所有/亚马逊/卖家）、价格上下界。页面初始读取后切换“亚马逊”筛选，显示 3 条变体；切换“卖家”筛选，显示 2 条商品组。该切换在本次事件窗口未捕获新增 XHR，初步更像对已载入列表的本地筛选；需下一轮重新启用事件游标重复确认，不能把一次空事件窗口当成协议结论。

“亚马逊”筛选下的行级动作包含：

- 编辑、管理图片、复制到新商品；
- 转换为“卖家自行配送”；
- 发/补货；
- 设置补货提醒；
- 查看亚马逊货件；
- 停售/出售、删除商品和报价、广告列表。

“卖家”筛选下的行级动作没有“发/补货”和“查看亚马逊货件”；顶部批量操作仍显示“转换为‘亚马逊配送’”入口。由于当前页面勾选控件在本轮出现交互超时，尚未提交批量转换，也没有产生状态写入。

## 4. 发/补货只读入口

从“亚马逊”筛选下的首个现有测试变体选择行级“发/补货”后，进入：

`/ECrossAmazon/SellerProductFBAStep1`

页面显示“要创建新入库计划还是添加至现有入库计划？”并提供：

- 创建新的入库计划（默认）；
- 添加至现有入库计划；
- 添加地址发货；
- “是，我想通过亚马逊运输货物”复选框；
- “继续处理入库计划”按钮。

页面表格字段：卖家 SKU、商品名称、状况、需要操作、商品数量、删除；本次页面总计为 0，未进入可提交的货件商品行，也未点击继续按钮。仓储监视器显示标准尺寸、大件、服装、鞋靴四类容量摘要，当前均为 0.00 立方英尺的空摘要状态。

这条证据补齐了“从现有 FBA 商品到入库计划起点”的页面结构，但不等于已验证创建货件请求。随后换用第二个现有 FBA 变体重复打开同一入口，页面仍为商品行 0、总计 0；因此当前更像账号/测试对象没有可补货数量，而不是单个 SKU 的偶发空态。要取得真实创建/确认请求，必须先有可用商品数量或专门测试对象。

## 5. 与旧脚本字段的对齐

旧资料中的补货片段使用 `GetOrderList`、`GetStockList` 及 `DS2083`、`DS4005/DS4006`、`B0101`、`DS5611`、`DS5617/DS5618` 等字段。本轮现场库存接口返回的是 `GetSellerProductList` 的 64 字段集合，未返回这些旧片段中的全部字段；因此当前标记为：

| 旧脚本字段/接口 | 当前 V2 现场状态 |
|---|---|
| `GetOrderList` | 已确认路径可读；当前返回空列表 |
| `GetStockList` | 本轮未在当前库存页事件中出现，待针对“亚马逊库存/库存补货”入口单独抓取 |
| `DS2083` | 在 `GetSellerProductList` 返回中出现，类型为字符串；业务语义仍需详情或编辑页交叉确认 |
| `DS4005/DS4006` | 本轮库存返回未出现，待订单/补货上下文验证 |
| `B0101`、`DS5611`、`DS5617/DS5618` | 本轮库存返回未出现，待专门库存接口验证 |

## 6. 后续缺口

1. 在不新建对象的前提下，继续读取商品详情/编辑页，确认 SKU、ASIN/UPC、配送类型、物流模板和变体关联字段。
2. 对“亚马逊库存”入口单独抓取接口，核对 `GetStockList` 或等价 V2 路径及 FBA 库存字段。
3. 若平台提供可用测试数量，再在单个现有测试对象上验证创建入库计划的真实请求、业务 Code/Msg 和列表回读；当前不伪造货件写入。
4. 订单为空时，继续记录空状态和会话恢复分支，不用猜测发货请求字段。

本文件不代表已执行商品转换、入库计划创建、发货或删除动作。

## 7. 亚马逊库存视图

从库存子菜单进入“亚马逊库存”后，仍使用库存列表路由，但页面标题和列集合发生变化：

- 页面标题：管理亚马逊库存；
- 记录数：当前视图显示 3 条变体行；
- 新增列：FNSKU、体积（立方英尺）；
- 保留列：状态、图片、SKU/状况、商品名称与 ASIN/UPC、创建/更新日期、可售、费用预览、价格与运费模板、操作；
- 行级动作：编辑、管理图片、复制到新商品、转换为卖家自行配送、发/补货、设置补货提醒、查看亚马逊货件、停售/出售、删除商品和报价、广告列表。

当前页面同时显示可售数量和“已达到补货提醒条件”的提示，说明补货提醒是库存视图的状态派生信息，而不是单纯的商品详情字段。体积字段以立方英尺显示，后续发货/仓储计算需要保留单位。

本次进入“亚马逊库存”没有在事件窗口捕获新的业务 XHR，页面可能复用了已加载库存数据并切换列视图；后续若要确认专用接口，需在清空事件游标后单独刷新该入口，再对照 `GetSellerProductList` 的请求上下文。

## 9. 按 SKU 查看亚马逊货件

在“亚马逊库存”首个变体的行级操作中选择“查看亚马逊货件”，进入：

`/ECrossAmazon/SellerStockFBAListBySku`

页面与全局货件列表分开呈现，字段为：

- 状态筛选：所有、处理中、在途、在运营中心、已完成、已删除/已取消；
- 货件名称、创建时间、上次更新、产品编号、SKU、数量、入库时间、状态；
- 分页默认每页 15 条。

当前按该变体查询显示 0 行和“无相关数据”。这进一步确认“商品具备 FBA/FNSKU”与“该 SKU 已有入库货件”是两个独立状态；不能因亚马逊库存页存在 FNSKU 就假设货件已经建立。2026-10-06 已补齐专用请求形状：`GetFBAPlanShipmentSKUList` 使用 `courseId`、`shopId`、`ds2301`、`ds2302`、`status`、`keyword` 包在 `arrayStr` 中；详见 [按 SKU FBA 只读证据](fba-sku-readonly-evidence-2026-10-06.md)。

# 买家消息只读页面证据（2026-10-06）

## 1. 页面入口

从卖家后台快捷入口“买家消息”进入：

```text
/ECrossAmazon/SellerMessageList
```

本次只读观察，没有打开消息正文、回复、发送或修改模板。

## 2. 页面结构和空态

- 页面标题为“消息”。
- 消息筛选下拉包含：所有消息、需要回复、未读、已发送消息、已接收消息。
- 页面提供搜索框 `katal-id-1`、搜索按钮和分页控件。
- 当前默认状态显示“没有需要回复的消息”，并提供“所有消息”按钮。
- 右侧“链接”区域提供“发送消息的权限”和“管理邮件模板”入口；本次没有进入这些页面。

## 3. 静态资源

页面专属脚本为：

```text
/Scripts/ECross/amazon/SellerMessageList.js
```

同时加载卖家后台共享布局、Kendo UI、语言和水印资源。当前现场只确认了页面和控件状态，没有把消息接口或消息正文写入资料。

## 4. 当前证据边界

已确认消息类型筛选、搜索、分页、空态和页面专属脚本入口。发送权限、邮件模板、消息详情和回复接口需要独立的非空消息对象，当前不通过猜测补齐。

| 历史文件 | 用途 | 状态 |
|---|---|---|
| `课赛通_亚马逊仿真_物流模板创建_历史参考.py` | 模板创建顺序、字段和选择器线索 | 历史候选，当前平台待复核 |
| `课赛通_亚马逊仿真_广告活动_历史参考.py` | 广告商品选择、预算与投放流程线索 | 历史候选，不把 FBA 筛选等同于转换 |

| `课赛通_亚马逊仿真_订单发货_历史参考.py` | 管理订单到发货及后续仓库步骤 | 需逐步骤对照真实请求和状态回读 |
| `课赛通_亚马逊仿真_FBA发货_历史参考.py` | FBA 变体、货件与发货线索 | 转换、筛选、库存、货件分别记录 |

本轮没有运行这些脚本，也没有直接上传可能包含登录信息的原代码。旧的发品/提分 TXT 即使内容相同仍保留业务上下文，不合并成一种逻辑。

## 平台事实与打法

平台审计与策略资料在本地核心工作区的 `docs/website-audit`、`docs/strategy-materials`。公开仓库 `main` 尚不包含同等完整的现场证据；已有历史策略分支为 [codex/strategy-materials-2026-09-23](https://github.com/fengzide86/kesaitong-platform/tree/codex/strategy-materials-2026-09-23/docs)，其状态和日期必须另行核对，不能标成最新全量审计。

开发前为每项资料标记：来源、日期、已确认/待确认/不兼容、只读/写入、成功回读证据、异常分支。新的 API 不从旧字段名猜测，也不从页面 HTTP 200 推断业务成功。

建议顺序：流程 → 字段与素材 → 旧代码线索 → 当前平台证据 → 工具契约 → 隔离与现场验收。评分表不是本轮主线，不将页面字段自动解释成得分点。

## 专项原件阅读顺序

以下是相对于核心开发工程的定位路径。完整审计和计算增量主要在本地 `课赛通-核心平台`；当前公开资料分支不包含这些全部原件。无法读取时登记“未取得”，向持有者取得指定文件，不把路径登记算成已同步全文。

1. `docs/website-audit/2026-10-02/README.md`：最新专项入口与历史结论覆盖关系。
2. 同目录 `DELIVERY-2026-10-06.md`、`00-全站结构与证据索引-2026-10-06.md`、`network-architecture-2026-10-06.md`：交付范围、页面和网络结构。
3. 同目录 `operation-readiness-map-2026-10-06.md`、`remaining-gaps-2026-10-06.md`：沿用 R0/R1/R2 和具体完成判据，不另建准备度总表。
4. 对应动作的 `fba-api-evidence`、`ad-api-evidence`、`template-api-evidence`、`live-api-evidence` 等已有专项：字段、编码、业务返回、关联对象与回读。
5. `docs/strategy-materials/2026-09-23/README.md` 与旧脚本：打法及历史逻辑；不能替代当前接口验证。

FBA 转换的指定样本已验证，不代表空货件查询后就能创建或发货。国内仓库及卖家确认有单笔成功证据，不代表异常、重复提交和跨会话恢复全部完成。具体状态和缺口只在原准备度地图与 [当前工程与成果](current-status.md)维护。

## 计算与新版平台准备

已有计算代码不是空白模块。当前定位为 `electron/freight/rate-pack.cts`、`electron/freight/desktop-freight-controller.cts`、`src/shared/freight/rate-engine.ts` 和 `workbook-parser.ts`；内置工具注册与远程适配器计算动作另行核对。

先读 `docs/freight-calculation-review-2026-10-08.md` 及审计目录的 `freight-rate-information-contract-2026-10-04.md`，再取得指定原表和测试。复核记录中的本地修正、独立模拟的虚构费率、正式安装包和平台实时价格是四件事；公开本分支未宣称包含全部修正。

接 V3 时分别登记原表来源/有效期、列映射、币种、单位、阶梯/进位/限重/附加费规则、平台选项值、规则版本及验收样例。没有原表或业务规则的项目保留缺口，不凭 V2 值补齐。旧文档中的数量与测试结果只对所列来源、日期和文件范围有效。

后续只补充本文件的定位入口；详细公式、请求和异常继续更新原专项，不另做第二套“接口总纲”。

# 产品分类与工作区

## 产品归属

课赛通 KST 面向亚马逊比赛与课程实训的效率需求。核心用户是参赛学生及代打团队，课程学员、教师、院校和培训机构是次级用户；不是课程平台或通用卖家 SaaS。官网模拟是产品体验模块，不等于 KST 的全部能力都是模拟。

稳定产品标识为 `KST`（Windows 与控制面）、`SITE`（官网及官网模拟）、`OPS`（运营工作台）；资料组为 `LEGACY-AMAZON`、`LEGACY-ALIEXPRESS`、`SHARED`、`FEISHU`。用这些标识归类，不因一次版本更新再改产品名或新建工程。

| 产品或资料组 | 内容 | 管理边界 |
|---|---|---|
| 课赛通官网 | 营销、品牌、咨询、下载入口、官网模拟体验 | 官网代码在核心仓库 `src/marketing`，用 `build:marketing` 独立构建；暂不拆仓库 |
| KST 平台 | Windows 客户端、后端、登录授权、管理员与代理、工具执行 | 核心仓库；正式业务网页版已下线，不因此删除桌面共用界面 |
| 运营工作台 | 运营业务、桌面助手、Edge 扩展及成员流程 | 独立工程和发布流程，不并入 KST 源码 |
| 旧亚马逊资料 | 旧比赛脚本、流程、物流计算、商品图片、课程参考 | 历史事实来源，不等于当前平台兼容实现 |
| 旧速卖通资料 | 客服、物流、知识库、历史截图 | 单独保留平台身份，不当作亚马逊证据 |
| 共用资料 | 品牌、商业资料、团队约定 | 只收跨产品材料；平台专用证据、源码和安装包各归原产品 |
| 飞书项目资料 | 需求、知识、流程、协作记录、已读取的表字段名线索 | 可移植快照与在线来源并存；不是完整表结构或业务后端数据库 |

## 本地工程名称

以下是 2026-10-09 盘点时的目录名称，仅用于与团队沟通，不要求其他机器复刻作者盘符。

| 工程名 | 归属 | 注意事项 |
|---|---|---|
| `课赛通-核心平台` | KST 与官网开发 | 混合未提交变更保留，不在本轮合并 |
| `kst-local-experience` | 本地体验候选 | Git 工作树，不是可随意删除的源码副本 |
| `kst-web-retirement` | 业务网页版下线基线 | 正式基线工作树；体验工程依赖链接指向这里 |
| `kst-release-1.8.13` | 历史发布基线 | 保留追溯；不因旧版本号就删除 |
| `运营工作台独立工具` | 独立运营产品 | 本次盘点未识别为 Git 仓库，不能据此覆盖或重新初始化 |
| `00_项目资料总索引` | 本地资料中心 | 主资料集、冷归档、机器清单和本地审计分别保留 |

整理集中的是资料归属，不是源码、环境或数据库。新源码回所属工程，新证据按产品/模块/日期归档，正式发布物由原发布流程管理。

产品边界只维护在本文件；分支、版本、当前待办和负责人统一见 [当前工程与成果](./current-status.md)，不要在这里再复制状态表。

# 本轮 GitHub 同步边界

目标：长期主仓库 `fengzide86/kesaitong-platform` 的独立资料分支 `docs/project-organization-2026-10-09`。目录为 `docs/project-materials/2026-10-09`；不发布 Release，不上传 ZIP，不改官网或软件版本。

## 实际同步

- 本轮分类、工作区边界、历史资料入口、整理结果、恢复方法、图片使用说明。
- 相对化、白名单字段的图片路径/图位/8 文件目录移动映射。
- 核验通过的商品素材及其长度/SHA256 清单；公开审查不通过的原件保持本地，不强行转换后上传。
- 飞书中 **KST 项目** 的资产目录、可读取的内容快照和实际覆盖说明。个人日常、群聊、其他个人资料不混入。

以 [发布文件清单](./manifests/published-files.json)、[素材审查](./manifests/material-review.json) 和 [飞书覆盖说明](./feishu/README.md) 为准，不将目录登记等同于文件正文已上传。

## 不同步

- 密码、Cookie、Token、私钥、验证码、完整 `paras` 或认证会话。
- 客户账号、订单原文和含这些内容的截图。
- `04_受控私有资料`、原始运行数据库、日志、缓存、其他对话未完成源码。
- 重复副本恢复区、未知格式文件、在用验收根目录截图和未经完整公开审查的 Office/PDF 原件。
- 历史所有权操作证据中的个人身份/权限截图。飞书权限不修改，本轮不是再次转移所有权。

本地原件不改写、不删除。公有分支中的排除不是本地清理动作，也不说明相关资料没有价值。

## 团队接手

获取本分支资料，先读 README。需要未同步原件时，由持有者按项目需要通过受控渠道提供，不能凭公开清单重建凭据或客户数据。后续若并入 `main`，需要单独核对合并内容和 CI；本轮只推资料分支，不触发正式安装器构建或部署。

本机完整资料库、冷归档、原审计日志继续作为事实来源。本分支是可读、可移植的共享层，不声明“全部资料、全部 API、全部飞书记录均已同步”。

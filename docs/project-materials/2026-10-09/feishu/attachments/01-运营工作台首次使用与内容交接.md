# 课赛通运营工作台｜首次使用与内容交接

团队副本整理日期：2026-10-07。来源：`运营工作台独立工具/TEAM-START.md`、`docs/学生优先使用说明.txt`、`KST运营工作台-桌面版交付说明.md`。本文保留成员实际操作与交接说明，原件未修改；软件版本、采集结果与最新缺口以验收记录及实际运行界面为准。

工作台供市场和运营人员制作课赛通宣传内容，默认读者是参赛学生；向学生介绍的产品是课赛通KST亚马逊赛训工具。运营工作台由每人在自己的Windows电脑上运行，数据和平台登录各自独立。

## 先安装，再确认实际连接

1. 使用负责人确认的同一交付版本。桌面应用和Edge助手分别安装：完整包中是`01-桌面应用`、`02-Edge插件`；桌面单包需要另取插件ZIP。
2. 双击桌面安装程序，安装后从桌面或开始菜单打开“课赛通运营工作台”，保持运行。
3. 打开`edge://extensions/`，开启开发人员模式，把插件ZIP拖入页面空白处；不接受ZIP时，解压后“加载解压缩的扩展”，选择直接含`manifest.json`的目录，并保留该目录。只启用一个助手，浏览器的安装确认由本人完成。
4. 查看工作台助手状态。收到回应后，在同一个Edge用户配置登录需要的平台，再点击“检查登录”，逐个平台核对。
5. 先选一个平台发起项目关键词研究。切换网页或关闭助手弹窗不会取消采集；再次打开可查看原任务进度。

助手连接、平台登录和结果保存分别判断。没有历史数据的新电脑也应显示真实连接；旧电脑在助手离线时应显示断开。“登录不确定”表示网页证据不足，保持待确认。

四个平台的完整在线采集链路仍待逐一通过。修订后的助手必须先收到实际运行版本及修订号，再复测；搜索样本不等于已确认同行或可发布选题。遇到登录、验证码、超时、没有相关内容或主页链接，记录具体提示。

## 一篇内容怎样制作和交接

1. 选平台，研究关键词，核对当前赛事与亚马逊赛训范围。分清近期项目内容、长期实用教程和结构参考；采集时间不替代真实发布时间。
2. 在创作助手选择选题。默认先面向参赛学生，每个平台采用自己的内容结构。
3. 查看“本次解决什么问题、用什么证明、下一步做什么”，核对实际带入的事实、版本、来源、配图与缺口。价格、交付范围不清楚就先补资料。
4. “复制文字任务包”后粘贴给网页版ChatGPT；“下载任务资料包”后先解压，仅附实际选中且批准的课赛通海报、当前软件截图、功能图、案例或品牌图。
5. 把生成正文粘贴回工作台，保存草稿，再进行发布检查。修改后的稿件需要重新检查；未检测、失败、资料不足均保留真实状态。
6. 将草稿和可访问内容包链接放进飞书“内容排期与审核”，提交审核；收到意见后修改，再提交。人工发布后填发布链接与实际数据。
7. “数据复盘”可导出JSON/CSV/ZIP包。只复盘自有账号发布表现；未知指标保留未填写，同行互动不作为自有业绩。

项目资料需要有效、已核验并允许公开引用。历史图片默认待确认；没有当前功能截图就标记待补，Logo只用于品牌识别。闲鱼介绍工具用途与交付范围，小红书、B站、抖音分别采用适合的内容结构。商品照片不作为课赛通功能证明。

源文件当前以“第七届全国数字贸易技能大赛/亚马逊赛训”作相关性配置；正式赛程、届次和报名资格仍应由负责人核对当下官方信息。其他赛事、其他届次和相邻平台样本只作结构参考。

## 成员试用怎样算完成

先由负责人带2—3人试用，第一位成员实际完成：安装→助手连接与版本确认→一个平台采集和保存→内容包复制→正文回填保存→检查→草稿交到飞书→重启后保留。

每项填真实进展、问题、成果链接与验证记录。本机自动测试不能填写为成员电脑通过。需技术配合时关联执行任务；内容制作本身继续在排期表推进。

分享导出包前查看是否含不宜传播的团队内容。数据目录和本机凭据保留在本人电脑，不用于替代安装或内容交接。助手不导出平台登录状态，发布、点赞、评论和私信由本人操作。

旧草稿保留当时的提示词与资料快照；资料许可撤销或过期后，旧包停止再次导出，已复制出去的材料也应重新核对和停用。

# 官网、桌面端与服务地址

本文件只维护入口、地址与构建用途。AI 接手顺序和填写规则见 [AI 指南](../AI_GUIDE.md)，产品及发布现状见 [当前工程与成果](project-materials/2026-10-09/current-status.md)。

## 当前产品入口

- 对外官网统一为 `https://kesaitong.top`，继续使用独立宣传站点的构建和发布流程。官网内容、设计和下载入口不因业务网页版下线而调整。
- 使用工具、登录账号、管理授权、管理员及代理业务均进入 Windows 桌面端。业务网页不再作为手机入口，也不再作为可安装的 PWA 发布。
- 原业务网页链接跳转到官网时不带原查询参数；原网页资源和安装清单返回停用状态。API、自动更新及安装包地址保持原有行为。

## 保留的构建用途

- `npm run build:marketing`：正式官网的独立构建，发布流程见 `docs/MARKETING_SITE.md`。
- `npm run build:desktop`：安装包内的共享界面；保持桌面控制面地址、更新地址、App ID 和用户数据目录。
- `npm run build:web` / `npm run build`：仅用于本地界面预览和浏览器 E2E 测试，不生成线上业务网页发布包。API 默认使用测试页面当前 origin 的 `/api/`；隔离验收显式传入的 `VITE_CONTROL_API_BASE` / `VITE_API_BASE` 仍生效。
- `npm run web:audit`：检查本地渲染产物可加载，且不包含 Service Worker、PWA 安装清单、网页版本文件或其注册入口。保留命令名以兼容本地测试调用。
- 桌面端仍使用自身更新中心；页面刷新更新提示和 `/web-version.json` 轮询已移除。

## 部署边界

服务器保留 `/api/`、`/updates/`、HTTPS 证书及原有续期能力。业务网页版清退只修改旧页面与静态资源的公开访问，保留共享源码供桌面软件使用。后续正式发布不再上传业务网页，也不再以公开网页版本文件作为发布验收条件。

旧网页的 Service Worker 清退响应由服务器单独提供，不重新打包进桌面端或本地渲染产物。线上旧资源核验后移到非公开备份，回退只恢复网页配置和文件，不恢复数据库。

未来若迁移桌面控制面到域名，需另外同步 API 配置、更新 feed、CSP 与必要跨域策略，并让旧安装包继续更新。本次不将旧 IP 的 API 和更新请求整体重定向到官网。

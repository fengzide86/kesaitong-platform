# KST 本地体验优化和验收入口

本轮在独立工作目录实施失败恢复、本机文件选择、旧客户演示清退和官网模拟体验。官网内容以已验收版本为准，价格、案例和营销设计不变；真实工具仍由原工具负责人开发。所有构建和验收仅在本机进行，不部署、不推送、不操作线上数据。

未修改其他对话使用的 `D:\开发项目\课赛通-核心平台`；不合并它的未完成源码。

## 恢复规则

执行状态和恢复分类分别保存。“人工核对已完成”不改成 Runner 成功；崩溃、超时和提交证据不足时保持待核对，主进程禁止直接重试。原子账本保存失败则不派发潜在提交，损坏账本保留原文件，不阻断登录和求助。

批次创建时登记每一行的原行号、输入指纹、工具版本和未派发状态，不保存原表内容。重新选择原文件后，只准备确定可重试的新批次；成功、未知结果和不匹配行排除。每次尝试使用新的授权幂等键和执行断点。没有本机证据的旧批次不能自动恢复。

C 端执行记录和 B 端批量记录均提供本机核对入口，可查看证据、打开平台、记录结论和导出失败清单。清单只含原行号、恢复分类和错误码，不含账户、密码或输入内容。退出授权会终止旧现场，保留账本及证据；迟到事件不能污染下一授权。

## 文件边界

工具文件参数通过选择、更换和清除按钮输入，仅展示文件名。取消选择保留已有值。主进程从已验证的工具目录取得文件字段，启动和每次上传都校验原生选择、窗口归属、存在和可读性，不能省略字段提示绕过检查。普通浏览器没有该桌面接口。

文件内容和完整路径不进入控制面记录。文件格式要求沿用现有工具说明，不增加猜测的扩展名限制。

## 官网模拟范围

旧版 `/demo` 曾包含简化的商品发布、库存/FBA、配送模板、推广、订单和仓库及五个任务。用户不接受该界面的还原程度，因此当前 `/demo` 改为亚马逊 V2 高还原首轮样板：课程地图、库存、八分页商品编辑与多行变体，另保留国内仓库订单链及两个一键任务。旧实现保留在源码及本地备份中，但不再是当前路由。范围与验收见 [V2_FIDELITY_ACCEPTANCE.md](./V2_FIDELITY_ACCEPTANCE.md)；FBA 转换、货件、推广和物流的完整页面未声称完成。

人工操作和一键任务使用同一套页面按钮、表单校验和保存回读；暂停、继续、停止和重置影响体验自身的状态，不访问真实平台。

数据保存在版本化的浏览器专用存储中，刷新保留；存储不可用时明确提示临时体验。重置只删除体验自己的样例。未接业务 API、授权、Runner、遥测或真实账号，不恢复下线的业务网页版，也未新增 Windows 模拟体验入口。

官网恢复真实咨询说明，Windows 真实执行与官网模拟分开表述。客户不再看到旧演示记录和再次演示按钮，旧数据及兼容 API 保留。删除不再引用的旧假咨询窗口和旧装饰演示场景；原版本可以从核心 Git 基线恢复。内部历史演示样例仅供显式测试，生产构建禁止模拟回退。

## 下载和后续发布边界

服务器配置准备了 `/updates/latest.exe`，由后端读取正式 `latest.yml` 解析已发布包并返回禁止缓存的跳转；清单错误、包不存在或元数据不匹配明确失败，不猜旧包。此配置本轮未部署，官网预览仍使用构建时核验的已发布 1.8.14 安装包地址，未提前启用稳定入口。

本地官网配置必须指定 `KST_MARKETING_PROVIDER=github-pages`、`GITHUB_PAGES_REPOSITORY=fengzide86/fengzide86.github.io` 和 `KST_MARKETING_SITE_URL=https://kesaitong.top`。这些是公开站点配置；账号令牌仍不进入源码。

候选安装包仍未签名，可能提示未知发布者。当前交付不包含生产部署、真实工具业务验收、真实手机设备测试或 Python 3.10 CI 兼容性证明；MariaDB 并发验收需要独立数据库环境。
